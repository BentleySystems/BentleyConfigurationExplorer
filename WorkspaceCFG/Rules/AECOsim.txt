#--------------------------------------------------------------------------------------------------------------------------
# AECOsim Rule file
#
#       Options:
#               MUST                                    - Creates Error Events
#               MUST_NOT                                - Creates Error Events
#               SHOULD                                  - Creates Warning Events
#               SHOULD_NOT                              - Creates Warning Events
#
#       Attributes:
#               BE_DEFINED                              - The variable is defined
#               BE_LOCKED                               - The variable is locked
#               BE_FOLDER                               - If defined the variable looks like a folder (can not look like a file)
#               BE_FILE                                 - If defined the variable looks like a file
#               BE_FILE_OR_FOLDER                       - If defined the variable looks like a folder or a file
#               BE_NUMBER                               - If defined the variable is a number
#               BE_BLANK                                - If defined the variable is blank or empty (no value)
#               HAVE_ONE_VALUE                          - If defined the variable has one and only one value (can be a blank value)
#               HAVE_FOLDER_EXIST                       - If defined the variable points to folder that exists (can point to file where the folder exists)
#               HAVE_FILE_EXIST                         - If defined the variable points to file that exists (in theory the folder must also exist)
#               HAVE_FILE_OR_FOLDER_EXIST               - If defined and if variable is a folder then folder must exist, if variable is file the file must exist
#               HAVE_WILDCARD_CHARACTER                 - If defined the variable has the wildcard character *
#
#       Attributes that require the <VALUE> field:
#               BE_LIKE                                 - If defined the variable expansion contains <VALUE>                - case insensitive
#               BE_NOT_LIKE                             - If defined the variable expansion does not contain <VALUE>        - case insensitive
#               BE_EQUAL_TO                             - If defined the variable expansion equals <VALUE>                  - case insensitive
#               BE_NOT_EQUAL_TO                         - If defined the variable expansion does not equal <VALUE>          - case insensitive
#
#       Vertical bar symbol | can be used to specify multiple values
#
#       Usage:
#               <VARNAME> <OPTION> <ATTRIBUTE>
#               <VARNAME> <OPTION> <ATTRIBUTE> <VALUE>
#
#--------------------------------------------------------------------------------------------------------------------------
